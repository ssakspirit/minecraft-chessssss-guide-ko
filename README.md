# 마인크래프트 CHESSssss — 한국어 안내서

마인크래프트 에듀케이션 라이브러리 수업 「CHESSssss」의 영문 안내서 *Minecraft Chess Guide for Players, Parents, and Coaches*를 한국어로 옮긴 **비공식 번역본**입니다.
원본의 배치·그림·표는 그대로 두고 글자만 한국어로 바꿨습니다. 게임 속 용어(체스 마스터, 숨겨진 폰, 루스터 쿨, 양철 골렘, 하늘·산·밀림 바이옴 등)는 월드의 공식 한국어 표기에 맞췄습니다.

## 월드 열기

월드 파일은 이 저장소에 없습니다. 마인크래프트 에듀케이션 → 라이브러리에서 「CHESSssss」를 찾아 「만들기」를 누르면 바로 시작합니다.

- 공식 수업 페이지: <https://education.minecraft.net/ko-kr/lessons/chessssss>

월드 안 대사는 게임 언어를 한국어로 두면 한국어로 나옵니다.

## 자료 (`자료/` 폴더)

| 파일 | 내용 | 영문 원본 |
|---|---|---|
| 마인크래프트_체스_안내서.pdf | 학습 목표 5가지, 맵 둘러보기, 네 가지 모드(튜토리얼·스토리·자유 플레이·퍼즐) 활용법, 바이옴별 AI 상대 표, 숨은 기능, 대회 여는 법 (7쪽) | Minecraft Chess Guide for Players, Parents, and Coaches |

- 대상: 8~13세, 1시간 안팎
- 표지 그림 속 글자는 그림이라 영어 그대로입니다.
- 원문에는 숨겨진 폰이 16개라고 되어 있지만, 지금 게임 화면에는 「1/8 숨겨진 폰」처럼 8개로 나옵니다. 번역은 원문대로 두었습니다.
